# MillionSend

**The open-source email platform. Send one. Send a million.**

Self-host on your own AWS SES, or use the hosted cloud. Resend-compatible API, so migrating is
two environment variables — not a rewrite.

## Repositories

| Repo | What it is |
|---|---|
| [millionsend](https://github.com/MillionSend/millionsend) | The product — dashboard, API, workers, self-host compose (AGPL-3.0) |
| [millionsend-node](https://github.com/MillionSend/millionsend-node) | Node.js SDK — npm: [`millionsend`](https://www.npmjs.com/package/millionsend) (MIT) |
| [millionsend-python](https://github.com/MillionSend/millionsend-python) | Python SDK — PyPI: [`millionsend`](https://pypi.org/project/millionsend/) (MIT) |
